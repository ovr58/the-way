# Палитра проекта по заливкам кадров

Снято скриптом с кадров макета (заливки, обводки, цвета сегментов текста) за вычетом «Запрос - Экран системы iOS» и «Запрос - Экран системы Android». Частота — число слоёв с этим цветом. В `design/tokens/colors.json` попали цвета с частотой ≥ 5; полностью прозрачные заливки (`@0`: `#ffffff@0` 348, `#d8d8d8@0` 34, `#ffff00@0` 10, `#db2121@0` 5) цветом не считаются. Имена — по роли слоёв, где цвет встречается; спорное решено по частоте. Прозрачность в токене — `$extensions.opacity`.
