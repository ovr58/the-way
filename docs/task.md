# Тестовое задание. Практическая часть

## Контекст:

> Приложение – аналог blablacar для малых городов РФ. Проблема, которую решает клиент, что из “одного села” в “другое село” сейчас ходят маршрутки, где по-прежнему все аналоговое (нужно прийти на место, найти водителя, договориться, ждать и тд). 
Клиент делает приложение, в котором пассажиры могут онлайн бронировать маршрутки, а водители – подтверждать пассажиров на поездку.
> 

## Задача:

- Вот часть дизайна приложения: https://www.figma.com/design/Lcc0mp04CCmLYfMLF2ZmzI/%D0%A2%D0%B5%D1%81%D1%82%D0%BE%D0%B2%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5?node-id=43-33059&t=g6a9z0MFhvaFUTkq-1
- Необходимо разработать указанный функционал. Фронт - Flutter, Бэк на ваш выбор

- Пара моментов:
    - Если у пользователя нет отзывов (а в рамках тестового у нас нет функционала оставления отзывов), то отображаем “5 звезд, нет отзывов”
        - При этом в базе данных полноценный функционал для отзывов пусть будет заложен
    - Сервис для отправки СМС НЕ подключаем. Захардкодьте на время тестового, что код везде 111111
    - Проверять будем на устройстве ВНЕ РФ (то есть разворачивать именно на РФ хостинге НЕ обязательно)
    - Оплату НЕ подключаем (просто при клике на “оплатить” - сразу переходим на “оплачено”)

## Формат сдачи:

- APK файл для тестирования приложения
- Архив с кодом (backend + frontend) для проверки

> Сервера должны работать! То есть нам нужна возможность просто взять и запустить (причем не только APK, но и запустим сборку командой flutter run).
> 

Файлы заливаете на google disk / яндекс диск и в чат отправляете ссылку. Просим проверить предварительно, что у ссылки есть доступ на чтение. Сами файлы в чат с менеджером отправлять НЕ НУЖНО – из-за ограничений по объему будут ошибки.
