# Данные приложения

## `car_catalog.json` — марки и модели автомобилей

Каталог для выбора марки и модели в форме «Добавление нового ТС». Читается клиентом из ассета, сервер
его не знает.

- **Источник:** [blanzh/carsBase](https://github.com/blanzh/carsBase), коммит
  `62b0427245dfb944caf03509d84391c5af20b1ae`, файл `cars.json` (426 марок, русские названия, годы).
- **Лицензия:** в репозитории источника не указана. Для тестового задания набор используется
  как есть; при выходе за рамки тестового задания условия
  использования набора надо уточнить у автора.
- **Сборка:** `node tools/data/build-car-catalog.mjs` скачивает файл этой версии и пишет
  `car_catalog.json`. Остаются марки, у которых есть модели с `year_to >= 2000`, и только такие
  модели; поколение из названия отрезается («Camry, VII (XV50) Рестайлинг» → «Camry»). Популярные
  марки идут первыми, дальше по алфавиту. Маршрутки и автобусы, которых в наборе нет, скрипт
  дописывает из своего списка `EXTRA` (ГАЗель Next и др., марка ПАЗ).
- **Формат:** `[{id, name, cyrillicName, popular, models: [{id, name, cyrillicName}]}]`. Поиск на
  клиенте — по `name` и `cyrillicName`, латиницей и кириллицей (ключ поиска `lib/src/app/search_key.dart`).
  Модели нет в каталоге — «Другая модель», свободный ввод 1–40 символов.
- **Правка вручную не делается:** меняется скрипт, файл пересобирается.
